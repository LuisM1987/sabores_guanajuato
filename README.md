# Sabores de Guanajuato (Flutter)

App informativa de recetas tipicas: Splash (3 s) -> Home (busqueda, categorias,
lista de tarjetas) -> Detalle (Hero, iconos, ingredientes, pasos, Favorito y Compartir).

Estructura: lib/models, lib/data (mock data), lib/screens, lib/widgets, lib/theme.
Las imagenes de assets/images son de MUESTRA: reemplazalas por tus fotos con los mismos nombres.

## Pasos
    flutter create .
    flutter pub get
    flutter run -d chrome      (o -d edge, o flutter run para Android)

## Entrega
- GitHub: sube la carpeta del proyecto (el .gitignore que crea Flutter ya excluye build/).
- Capturas: Splash, Home, Home con filtro/busqueda y Detalle.
